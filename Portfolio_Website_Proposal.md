# Personal Portfolio Website Proposal

**Prepared for:** Sivakumar Dhanushka
**Role Focus:** IT Infrastructure Intern | ERP/SAP Support | Full-Stack Developer
**Date:** August 2026

---

## 1. Overview

This proposal outlines the plan to design and develop a personal portfolio website for Sivakumar Dhanushka. The site will serve as a professional online presence showcasing his skills in IT Infrastructure, ERP/SAP, Database Management, and Full-Stack Web Development, along with his academic background, certifications, and project work — including the MERN-stack E-Commerce Website project.

The goal is to present a clean, credible, and recruiter-friendly platform that supports internship and job applications in IT Infrastructure, ERP/SAP Support, and Software Development roles.

---

## 2. Objectives

- Build a single-page or multi-page responsive portfolio website.
- Clearly communicate the dual specialization: **IT Infrastructure/ERP support** and **Full-Stack Development**.
- Showcase completed projects (starting with the MERN E-Commerce platform) with descriptions, tech stacks, and links (GitHub/live demo).
- Provide easy access to resume (PDF download), contact details, and social/professional links (LinkedIn, GitHub).
- Establish credibility through certifications, education, and skills sections.
- Ensure the site is fast, mobile-responsive, and easy to maintain/update.

---

## 3. Target Audience

- Recruiters and HR personnel screening for IT Infrastructure, ERP/SAP, or Software Development internships.
- Potential employers reviewing full-stack development capability.
- Academic supervisors or industry mentors (SLIATE, industry partners).

## 5. Recommended Tech Stack

Given the skill set already listed on the resume, the portfolio itself can double as a **live demonstration** of full-stack ability:

- **Frontend:** React.js (or Next.js for SEO benefits and fast page loads)
- **Styling:** Tailwind CSS for a clean, modern, responsive design
- **Backend (optional):** Node.js + Express for a contact form API, or a simple form service (e.g. Formspree) to avoid backend overhead
- **Database (optional):** MongoDB, only if dynamic content (e.g. an admin-editable project list) is desired
- **Deployment:** Vercel or Netlify (frontend), Render/Railway (if backend is included)
- **Version Control:** GitHub (also links back to the portfolio as a project itself)

---

## 6. Design Direction

- Minimal, professional layout with a dark or navy-and-accent color scheme (fits IT/tech branding).
- Clear visual separation between the **Infrastructure/ERP** side and the **Development** side — e.g. using tabs or a toggle, or icon-based skill cards.
- Resume downloadable as PDF directly from the site.
- Mobile-first responsive design, since many recruiters browse on mobile.
